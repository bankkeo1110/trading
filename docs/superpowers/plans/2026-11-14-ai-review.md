# Chấm đúng/sai, thống kê và AI review — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tự chấm đúng/sai mọi gợi ý mua/bán đã gửi, thống kê, và mỗi tuần để Claude CLI viết báo cáo + đề xuất chỉnh tham số mà người dùng duyệt trên dashboard.

**Architecture:** Chấm và thống kê bằng Python thuần trong lượt quét (dùng nến đã tải sẵn). Tham số khai báo một chỗ (`web/params-spec.json`), lưu ở dòng `advice.*` của `settings.properties`. Workflow riêng gọi `claude -p` với JSON schema, kiểm tra kết quả rồi lưu vào nhánh data và gửi Telegram; dashboard ghi tham số qua API Vercel.

**Tech Stack:** Python 3.12 stdlib, GitHub Actions, Claude Code CLI (`@anthropic-ai/claude-code`), Vercel serverless (Node), HTML/JS thuần.

**Spec:** `docs/superpowers/specs/2026-11-14-ai-review-design.md`

## Global Constraints
- Đúng = chạm chốt lời 1 trước cắt lỗ trong 24 nến; nến chạm cả hai tính Sai; quá 24 nến là Hết hạn.
- CANH MUA/BÁN: đúng/sai theo giá đóng sau 12 nến.
- Dưới 30 tín hiệu đã có kết quả: không đề xuất chỉnh.
- Mỗi đề xuất đổi tối đa ±30% so với giá trị hiện tại và phải nằm trong min/max của spec.
- Review: tối Chủ nhật giờ VN. Xác thực: `CLAUDE_CODE_OAUTH_TOKEN`, dự phòng `ANTHROPIC_API_KEY`.
- Mọi chữ hiển thị bằng tiếng Việt có dấu.

## Review Focus
- Tín hiệu cũ (bản đầu) thiếu `sl`/`zone`/`params_id`: phải được bỏ qua hoặc chấm được, không làm lượt quét lỗi.
- Nến tín hiệu đã trôi ra khỏi cửa sổ 300 nến: đánh dấu không chấm được, không lặp lại mãi.
- Claude trả JSON hỏng / không có token: vẫn gửi bản thống kê, workflow không làm hỏng nhánh data.
- Hai workflow cùng ghi nhánh data: push phải rebase, không mất dữ liệu của bên kia.
- Áp dụng tham số làm `hold >= weak` hoặc `tp1 >= tp2`: API và review phải từ chối.
